# Week 01 AI Assistant Comparison

## Common question

What is the difference between SRAM and DRAM?

I used the same question with Gemini, then used Google Search to find information about the same question. Finally, I checked the important points using an authoritative technical reference from Intel.

## Tool 1 - AI Assistant

Name: Gemini

### Answer summary

Gemini explained that SRAM stores data using flip-flops and does not require periodic refreshing. DRAM uses a transistor and capacitor to store data and requires periodic refreshing.

It also explained that SRAM is generally faster and more expensive, while DRAM is generally slower, cheaper, and has higher memory density. SRAM is commonly used for CPU cache, while DRAM is commonly used as main memory.

### Strengths

- Gave a quick explanation of the topic.
- Explained the basic difference in simple terms.
- Included differences in speed, cost, density, and usage.
- Helped me understand the topic before checking technical sources.

### Weaknesses

- The answer was generated by AI, so I still needed to verify the important technical claims.
- The answer did not by itself provide the same level of traceability as an authoritative technical reference.

## Tool 2 - Search Engine

Name: Google Search

### What I found

I searched for the difference between SRAM and DRAM using Google Search.

The search results showed different webpages explaining the storage method, refresh requirement, speed, cost, density, and common uses of SRAM and DRAM.

Google Search was useful for finding different sources, but the search engine itself was not treated as the final authority. I had to look at the actual sources and check their reliability.

### Strengths

- Helped me find multiple sources quickly.
- Allowed me to compare information from different websites.
- Made it easier to find a technical reference for verification.

### Weaknesses

- Search results can come from sources with different levels of reliability.
- A search result itself does not prove that the information is correct.
- I still needed to check the actual source.

## Verification Source - Authoritative Reference

I used the Intel External Memory Interface Handbook to verify the important technical information.

## Final Comparison

| Method | What it is useful for | Accuracy / reliability | Traceability | Explanation quality | Ease of verification |
|---|---|---|---|---|---|
| Gemini | Getting a quick explanation and understanding a topic | Needs verification | Medium | Good | Medium |
| Google Search | Finding different sources and information | Depends on the source | Good when the source is reliable | Varies | Good |
| Intel authoritative reference | Verifying important technical information | High for the documented information | High | Technical and detailed | Good |

## Differences I Found

The main information given by Gemini was consistent with the information I found through Google Search and the Intel reference.

I did not find a major incorrect claim in the Gemini answer. However, the comparison showed that an AI-generated answer should still be checked against a reliable technical source.

Google Search was useful for finding information, but it was not the final authority. The Intel handbook was more useful for verifying the technical details because it is an authoritative engineering reference.

## When I Would Use Each Method

I would use an AI assistant when I want a quick explanation or want to understand a technical topic in simpler language.

I would use a search engine when I need to find different sources, documentation, or technical information.

I would use an authoritative or primary reference when I need to verify an important technical claim or before making an engineering decision.

## Lesson

This comparison taught me that AI assistants, search engines, and authoritative references have different purposes.

An AI assistant can help me understand a topic quickly. A search engine helps me find relevant information and sources. An authoritative reference is more suitable when I need reliable and traceable technical information.

For important engineering work, I should not stop at the AI answer. I should verify the important claims using an appropriate reliable source.
