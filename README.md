## About Me

Hi, I am Govardhini Devi Machupalli. I am an Electronics and Communication Engineering student interested in VLSI, Embedded Systems, and Design Verification.

This repository contains my work for the 16-week VLSIGuru AI Literacy Layer program.

## About the 16-Week AI Literacy Layer

The purpose of this program is to learn how to use AI as an engineering learning and productivity tool while also understanding its limitations.

During the program, I will learn how to:
- Understand basic AI and machine learning concepts
- Use AI tools for engineering-related tasks
- Verify AI-generated information
- Compare information from AI tools, search, and reliable technical sources
- Document experiments and results
- Develop better problem-solving and verification habits
- Apply AI carefully in future VLSI and engineering work

## My Verification Approach

One important lesson from Week 01 is that an AI-generated answer should not automatically be treated as correct.

My basic approach is:

```text
Define the problem
        ↓
Ask / investigate
        ↓
Inspect the result
        ↓
Verify important information
        ↓
Document the evidence
        ↓
Reflect and improve
